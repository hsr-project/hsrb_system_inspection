概要
====

* HSRデバイス診断ツールの提供

目的
====

* 日常点検や異常時に、ユーザがロボットの状態を簡単に把握するために使用する


開発関係者
==========

* 橋口優香


診断の概要
==========

* デバイスは全19個。
* R501から5デバイス追加。切替は環境変数ROBOT_VERSIONを使ったlaunchファイル切替により行う。
* デバイスの診断は、それぞれのデバイスの属性に応じて、通信チェック・ROSmsgデータチェック・インタラクティブチェックの任意の組み合わせで行う。
　
* 近接センサ・駆動系停止・非常停止ボタンは診断をすることでロボットのコントローラがおちるため、デフォルトでwui上から見えないようにしてある。

* 診断は、各デバイスに1つ、ROS Actionの形で実装。インタフェースは以下の通り。

```
    <hsrb_auto_diagnostics/HsrbDeviceCheckAction>
    # goal
    —
    # result
    bool ok
    string error_msg
    —
    # feedback
    string feedback_msg
```

通信チェック
==============

* デバイスとの断線異常、通信異常を検知する診断の第1段階。

* USB接続の確認やデバイスドライブでの認識、ネットワーク通信の確認を行う。


ROSmsgデータチェック
==========

* Subscribeしたセンサのメッセージデータに異常がないかを調べる。

* 例：データ欠損の有無、取得周期、はりつきの有無、データレンジ等を調べる。


インタラクティブチェック
==========

* デバイスの特性上、ユーザに作業や判断を依頼する必要がある場合のデバイス固有のチェック。
